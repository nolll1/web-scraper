Web Scraping Project

A simple web scraping project built using Python and Playwright.
This project demonstrates how to extract structured data (such as articles, titles, images, and links) from dynamic websites.

Features
Scrapes dynamic websites using Playwright
Handles lazy-loaded images (src / data-src)
Extracts structured data (title, link, image, category, etc.)
Supports navigation across pages/sections
Outputs data in JSON format

🛠️ Tech Stack
Python 3.12
Playwright (Chromium)
JSON for data storage
